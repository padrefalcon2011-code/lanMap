# LanMap — правила для ИИ-агентов (Claude Code, Codex)

Программа для среза, опознания устройств и наведения порядка в локальной сети. Полная концепция: [docs/CONCEPT.md](docs/CONCEPT.md). Прочитай её перед началом работы.

## Статус
Этап 0 (прототип) в работе: срез → модель «устройство по MAC» → опознание по правилам → HTML-отчёт уже работают. Код — пакет `lanmap/` (только стандартная библиотека), тесты — `python -m unittest discover -s tests` (адреса только RFC 5737, тест-сторож ловит частные IP и MAC в пакете). Реестр и правила — JSON. Правила опознания — `lanmap/fingerprints/rules.json`, пользовательские — `data/fingerprints/*.json`. После правки правил отчёт пересобирается без сканирования: `python -m lanmap build`. Папка `legacy/codex-2026-11-16/` — образец от Codex: брать идеи и куски сборщиков, но не запускать как часть программы и не править. `legacy/` и `data/` в git не попадают. Личные заметки по сети автора (срочные находки) — `data/NOTES.md`.

## Жёсткие правила
- **Ничего не менять на устройствах сети.** Только чтение: никаких подборов паролей, эксплойтов, записи настроек, создания или удаления пробросов. Исправления делает человек по инструкции, программа перепроверяет.
- **Ни одного IP, MAC, имени интерфейса или устройства конкретной сети в коде.** Всё определяется автоматически или берётся из `data/`.
- **Сканировать только локальные подсети компьютера.**
- **Личные данные только в `data/`** (он в `.gitignore`). Не коммитить срезы, реестр, отчёты с MAC и пароли. Пароли хранятся в диспетчере учётных данных Windows (`keyring`).
- Опознание объяснимо: у каждого вывода список улик и уверенность.
- Срезы не перезаписываются: каждый запуск сохраняется в новую папку.

## Пользователь
Общаться на «ты», по-русски, доходчиво. Перед крупными решениями — обсуждение; пользователь хочет сначала пощупать приближение, потом уточнять.

## Окружение
Windows 11, Python 3.14, запуск с правами администратора. Сеть автора: роутер Keenetic, NAS Synology, камеры XM530 (подробности — в legacy-отчёте, не в коде).
